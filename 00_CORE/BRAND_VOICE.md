# Brand Voice

- Third-person observer
- Calm, restrained, factual
- Approx. 145–155 WPM target
- Approx. 10–14 words per utterance unit
- No exclamation culture
- No hype language
- No rhetorical questions in narration
- Plain-language default; technical density only where mechanism requires it
- State uncertainty explicitly
- Use dates, measurements, report names, and official findings naturally

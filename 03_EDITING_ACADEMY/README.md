# EDITING ACADEMY
**Built 2026-10-04 from the YouTube Documentary Creative Intelligence research (2026-10-03).**
**No new research was conducted for this build. Every claim traces to the evidence files listed below.**

## Editorial promise this academy serves

*We investigate catastrophic failures by reconstructing the chain of decisions, warnings, mistakes, and system failures that turned a situation into a catastrophe.*

The chain is the protagonist. The edit exists to make causality visible:

**CAUSE → WARNING → DECISION → ESCALATION → POINT OF NO RETURN → FAILURE → INVESTIGATION → LEGACY**

This is not a generic YouTube editing system. Do not apply these patterns to other formats without re-validating.

## Honesty labels used throughout

- **[OBSERVED]** — directly evidenced by metadata, transcript, thumbnail, description, or chapter map.
- **[INFERRED]** — reasonable deduction from structure/reputation; never presented as measured.
- **[RESEARCH GAP]** — the research could not observe this (notably: actual sound design, true shot durations, cut frequency — no video playback was available). Rules in these areas are conservative and marked accordingly.

## Contents

- `reference_videos/` — 12 curated references (Tier A essential, Tier B highly useful, Tier C specialized technique). Study mechanisms, never identities.
- `documentary_patterns/` — 16 recurring editing patterns, each with purpose, usage rules, visual sequence, timestamps, mistakes, and Chain-of-Failure application.
- `edit_decision_rules/` — 13 operational IF/THEN rule files an editor or editing agent can follow directly.
- `music/MUSIC_RULES.md` — music rule system per story phase (presence, reduction, silence, density, restraint).
- `sound_design/SOUND_DESIGN_RULES.md` — SFX, transitions, silence, stingers, restraint.
- `EDITING_BENCHMARK_90SEC.md` + `benchmarks/SCORING_RUBRIC.md` — the 90-second editing benchmark: spec, inputs, outputs, 0–4 scoring per dimension, pass/fail thresholds.
- `LEARNED_RULES.md` — the growing rule set, separated into HIGH / MEDIUM / EXPERIMENTAL confidence. Update this file as new evidence arrives.

## How to use this academy (for an editor or editing agent)

1. Read `LEARNED_RULES.md` first (the distilled rules).
2. Read the `edit_decision_rules/` files relevant to the passage you are cutting.
3. Consult `documentary_patterns/` for the structural device the passage needs.
4. Check `reference_videos/` for the closest mechanism example — copy the *mechanism*, never the creator's identity or style.
5. Validate against the Channel Creative Bible's 9 pre-publish gates (they are the final authority).

## Update discipline

- New rules enter `LEARNED_RULES.md` as EXPERIMENTAL with their evidence attached.
- A rule is promoted only on new measured evidence, never on taste.
- Never invent timestamps, metrics, or observations. Mark uncertain observations as such.
- The Channel Creative Bible is preserved unchanged; if evidence contradicts it, propose the change explicitly — do not silently edit the standard.


## Relationship to the permanent production system

The Editing Academy is the editing intelligence layer. The one-time bootstrap provisions the actual media/toolchain needed to execute these rules. Do not confuse a written rule with a validated execution; system-level lessons belong in `09_SYSTEM/` and measured editing lessons belong in `LEARNED_RULES.md`.

# Pattern: MAP_SEQUENCE

## Purpose
Orient the viewer in space: where the system was, where the failure traveled, where the warnings were. Maps are stand-ins where archival footage doesn't exist and orientation where the story is geographic.

## When to use
- Any failure with a geographic footprint: dam + downstream valley, ship + route, plant + surrounding town, flood + basin.
- Countdown/real-time structures: the moving position marker is the clock made spatial.
- When the narration names places the viewer can't picture (basin names, shoals, bays).

## When NOT to use
- When the failure's geography is irrelevant to the causal chain (a factory-floor mechanism failure needs a diagram, not a map).
- As decoration between unrelated beats — every map appearance must answer "where" for the current narration.

## Narrative situation
Confident-system block (establishing geography), escalation (the failure's path), aftermath (the damage footprint).

## Visual sequence
1. Wide establishing map: the region, labeled, with the subject marked.
2. Push-in to the operational scale: the dam, the shipping lane, the plant.
3. Animated path/overlay: the flood's advance, the ship's track, the typhoon's approach, the warning locations lighting up in sequence.
4. Hold on the final footprint while the toll/scale lands.

## Typical duration
8–20 seconds per map beat. The animated path should match the narration's timeline (e.g., the flood advancing as the narrator names the towns).

## Motion strategy
The map itself is the motion: animated overlays, advancing fronts, lighting-up markers. Camera moves on the map should be slow pushes following the path direction.

## Transition strategy
Hard cut into the map; hard cut out. The map is a beat, not a transition.

## Sound strategy
[RESEARCH GAP.] Conservative: no SFX for map animation (it's orientation, not action).

## Common mistakes
- The spinning-globe intro (generic, says nothing about *this* failure).
- Unlabeled maps (a map without labels is decoration — the viewer must read place names).
- Modern satellite imagery presented without credit or, worse, implied as archival (honesty gate — credit the stand-in on screen).

## Chain-of-Failure application
Use the map to make the chain spatial: mark each warning location as the warnings beat unfolds; animate the failure's path as the escalation tightens. The viewer should be able to point at the map and say where each link happened.

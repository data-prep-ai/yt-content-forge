# DIAGRAM_DECISION — when the editor uses a diagram

## The question it answers
"When should we use a diagram?"

## Operational rules

- IF narration names a part, a reading, or a location on the structure → THEN the diagram must show it at that moment. Every technical noun gets a visual anchor.
- IF the mechanism is invisible (inside a foundation, inside a preventer, inside a hull) → THEN diagram first; cutaway for the full sequence (see MECHANISM_CUTAWAY — one per video).
- IF the narration gives numbers (dimensions, pressures, tolls over time) → THEN the numbers go on the diagram as labels or live counters, not as narration-only. Numbers need a surface.
- IF the viewer already understands the mechanism → THEN do not add another diagram. One clear diagram per mechanism; repetition is clutter.
- IF the diagram would need more than ~3 annotations to be understood → THEN it's two diagrams. Split it. (Maximum 3 marks per image — the clutter rule.)
- IF an archival photo shows the mechanism adequately → THEN annotate the photo instead of drawing a fresh diagram (the Plainly Difficult red-circle model [OBSERVED]).

## Annotation discipline (the "draw the failure" layer)

- Annotations appear one at a time, in narration sync (~2–3 seconds apart) — never all at once.
- The mark lands on the noun: the circle appears as the part is named.
- Style: flat, red, technical. No glows, no 3D bevels, no bouncy animation (restraint).
- Live counters (the USCSB "Gas Barrels Accumulation 207" model [OBSERVED]) turn a diagram into a countdown — use for accumulating quantities.
- Every moving part in a cutaway is labeled or narrated. An unlabeled animation is a screensaver.

## The diagram/cutaway boundary

- Static relationship (where is the crack?) → annotated diagram.
- Process over time (how did the water move?) → mechanism cutaway, once per video.
- When in doubt, start with the annotated diagram. It's cheaper, clearer, and the genre's signature layer.

## Anti-patterns

- Annotating everything (if every part is circled, nothing is circled).
- Annotations out of sync with narration.
- Decorative 3D diagrams (the genre's diagram language is flat and technical, not glossy).
- The unexplained cutaway (see MECHANISM_CUTAWAY mistakes).

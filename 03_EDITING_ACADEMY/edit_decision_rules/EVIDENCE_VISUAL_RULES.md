# EVIDENCE_VISUAL_RULES — showing proof on screen

## The principle
"When should narration be supported by evidence on screen?" — Whenever the narration makes a claim the record can show. The viewer should feel the paper trail under the chain.

## Operational rules

- IF narration states a finding (the report concluded X) → THEN the report page appears, push-in to the passage, key phrase highlighted. Claim and paper agree.
- IF narration quotes a person (the engineer, the investigator, the survivor) → THEN identify the source on screen if the record supports it (name, role, date). Never a floating quote.
- IF narration gives a disputed number → THEN show the dispute: the competing figures, sourced, with the uncertainty stated on screen (the Banqiao model: "show you exactly how and why rather than pick one for effect" [OBSERVED]).
- IF narration corrects itself or the record → THEN show the correction (the Fascinating Horror CORRECTIONS-section model [OBSERVED]). Corrections build trust; hiding them destroys it.
- IF the evidence is a number over time (toll revisions, pressure readings, water levels) → THEN it goes on a diagram or data graphic, not as narration-only.
- IF no evidence exists for a claim → THEN either cut the claim or say so on screen ("the record is silent here"). Never illustrate an unevidenced claim with a confident visual.

## Sourcing on screen

- Documents: source named (report title, agency, year) — in the video's source list at minimum; on screen for the key beats.
- Stand-in imagery: credited + labeled as representative (the GEO-KOMPSAT model [OBSERVED]).
- Reconstructions: labeled "dramatized/illustrative" on screen for the duration (see DISCLOSED_RECONSTRUCTION).
- Archival: source named in the source list (the Bureau of Reclamation public-domain model [OBSERVED]).

## Anti-patterns

- The confident visual on an unevidenced claim (the most dangerous honesty failure — the viewer trusts what they see over what they hear).
- Evidence montages (five documents flashing past = zero credibility; one document held = evidence).
- Selective quotation that reverses a source's meaning (honesty gate — quote fairly or don't quote).
- Fabricated documents, memos, or "recreated" evidence presented as real (hard ban).

# MAP_DECISION — when the editor uses a map instead of footage

## The question it answers
"When should the editor use a map instead of footage?"

## Operational rules

- IF narration names places the viewer can't picture (basin names, shoals, bays, towns downstream) → THEN use a map. The viewer must be able to point at where each link happened.
- IF the failure traveled (flood path, ship track, storm approach, debris field) → THEN animate the path on a map. The moving path is the escalation made spatial.
- IF the story is geographic but no archival footage of the place exists → THEN map/satellite imagery is the stand-in (credited — the Banqiao GEO-KOMPSAT model [OBSERVED]).
- IF the failure's geography is irrelevant to the causal chain (a factory-floor mechanism, a cockpit sequence) → THEN do not use a map. Use a diagram. A map of irrelevant geography is decoration.
- IF the map would only appear once for <5 seconds → THEN consider whether the place name can be carried by narration alone. Maps earn their beat; they don't decorate transitions.

## Map construction rules

- Every map is labeled: place names, the subject marked, scale legible. An unlabeled map is decoration.
- The establishing view is wide (the region); then push to operational scale (the dam, the lane, the plant).
- Animated overlays advance in narration sync: the flood reaches the town as the narrator names it.
- Modern satellite imagery used as stand-in is credited on screen (source + "representative imagery" where applicable — the Banqiao disclosure [OBSERVED]).
- No spinning-globe intros. No 3D fly-throughs. The map is orientation, not spectacle.

## Anti-patterns

- The decorative map between unrelated beats (every map appearance must answer "where" for the current narration).
- Unlabeled or illegible maps (if the viewer can't read the place names, the beat fails).
- Satellite imagery implied as archival (honesty gate — credit the stand-in).

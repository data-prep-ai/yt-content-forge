# MOTION_RULES — when stills move, how they move, when they don't

## The questions answered
"When should a still image be animated?" / "When should the screen become simpler?"

## Operational rules

- IF a still must hold the screen for more than ~3 seconds → THEN it gets exactly one slow directional move (push-in, pull-back, or lateral pan). No static frame holds past ~8 seconds.
- IF the narration names a detail visible in the still → THEN the move ends on that detail. Motion is editorial: it tells the viewer where to look.
- IF the still is a document being read as evidence → THEN near-stillness with a slow push to the passage. Documents get reverence; photos get survey. (See DOCUMENT_EVIDENCE.)
- IF the visual is a diagram receiving annotations → THEN the annotations are the motion; keep camera movement minimal or zero. The eye follows the marks, not the frame.
- IF the visual is a mechanism cutaway → THEN the mechanism moves; the camera stays nearly still. The process is the motion.
- IF the audience already understands what they're looking at → THEN simplify: hold still, reduce motion, clear overlays. Motion is for orientation and emphasis, not decoration.
- IF the beat is the catastrophe → THEN decelerate: longer holds, minimal motion. Stillness carries weight.

## Move vocabulary (one move per still — never combine)

- **Push-in** = intimacy / escalation (toward a face, a breach, a detail).
- **Pull-back** = context / scale (revealing the surroundings, the aftermath footprint).
- **Lateral pan** = survey / reading (across a scene, along a document, following a path).
- Speed: slow, single-direction, constant. Fast or multi-direction moves read as slideshow panic.

## Anti-patterns

- Identical slow zoom on every still (vary direction; the pattern is *movement*, not *zoom*).
- Zooming on faces for emotional effect (sentimentality the genre doesn't use).
- Sonifying photo moves (movement is not action — no whooshes on Ken Burns, ever).
- Motion on every element at once (moving photo + appearing annotations + panning map = visual noise; one moving thing per beat).

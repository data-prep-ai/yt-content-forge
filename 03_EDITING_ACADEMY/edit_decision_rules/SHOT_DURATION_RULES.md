# SHOT_DURATION_RULES — when to hold, when to cut

## The questions answered
"When should a visual change?" / "When should we deliberately hold a shot?"

## Operational rules

- IF the narration introduces a new idea (new link, new warning, new place) → THEN change the visual. One idea, one visual — the genre's ~12-ideas-per-minute band implies a visual change roughly every 5 seconds at cruise [OBSERVED cadence proxy].
- IF the narration continues the same idea (elaboration, evidence, quotation) → THEN hold or evolve the current visual (push-in, annotation appearing) rather than cutting away. Cutting on every sentence fragments comprehension.
- IF the visual is a document being read → THEN hold 8–15 seconds. The viewer needs reading time. The push-in to the passage is the only motion.
- IF the visual is the mechanism cutaway → THEN hold 45–120 seconds. The longest single hold in the video. Do not intercut away mid-mechanism.
- IF the beat is the catastrophe → THEN hold longer than anywhere else. Deliberate holds on the aftermath image while the toll lands. This is the hold the viewer remembers.
- IF the beat is the point of no return → THEN hold 2–3 seconds of near-stillness before the catastrophe begins. The held breath before the fall.
- IF the final image of the video → THEN hold 3–5 seconds. Then end. No fade-out montage.

## Hold durations (guidance, not law)

| Beat | Typical hold |
|------|--------------|
| Standard visual at cruise | 4–6 sec |
| Archival still with move | 4–8 sec |
| Document evidence | 8–15 sec |
| Annotated diagram beat | 10–30 sec |
| Mechanism cutaway | 45–120 sec |
| Catastrophe image | longest in video |
| Final image | 3–5 sec |

## Anti-patterns

- Cutting on every sentence (fragments comprehension — the visual should evolve within an idea, cut between ideas).
- The restless edit: changing visuals faster than the narration's ideas (the viewer stops seeing and starts enduring).
- Holding past the idea's end (dead air — when the narration moves on, the visual must move on).
- Intercutting away from the mechanism mid-explanation (the cutaway is the climax — protect its hold).

# TEXT_OVERLAY_RULES — when text appears on screen

## The questions answered
"When should text appear?" / "What may text say?"

## Operational rules

- IF a chapter begins → THEN the chapter title appears on screen. Chapter titles are a second title track (Bible §4.6) — the on-screen text mirrors them.
- IF the narration states a thesis the video will now prove → THEN the thesis may appear as a text beat ("HIT SECOND. FELL FIRST." [OBSERVED — thumbnail/chapter]). Maximum one thesis text per major section.
- IF a number is the point (the toll, the measurement, the counter) → THEN the number appears large, alone, held. Numbers need a surface.
- IF a document is shown → THEN at most one phrase is highlighted/underlined. The highlight is the annotation, not decoration.
- IF the point of no return is named → THEN it appears as text, held in stillness.
- IF uncertainty must be disclosed → THEN the disclosure appears as text ("the record is disputed here" — the Banqiao model [OBSERVED practice]).
- IF AI reconstruction appears → THEN the "dramatized/illustrative reconstruction" label appears on screen, visible, for the duration (see DISCLOSED_RECONSTRUCTION).

## Hard bans (Bible gates)

- **No stingers on death tolls. Ever.** The toll appears flat, held, silent — never with impact effects.
- No more than ~8 words per text overlay (the thumbnail research found text never exceeds 8 words among winners; on-screen text should be tighter still — aim ≤5).
- No arrows/circles as decoration (annotation marks are functional only — they point at the failure, not at the viewer's attention).
- No "subscribe" / "comment" text interrupting the documentary (the genre doesn't do it; the end screen handles it).

## Style

- Flat, technical, legible. The genre's text language is the report, not the movie poster.
- Thesis texts ("62 DAMS GONE", "HIT SECOND. FELL FIRST." [OBSERVED]) are the exception that proves the rule: short, factual, devastating — never adjectival.

## Anti-patterns

- Text walls (paragraphs on screen — the viewer can't read and listen simultaneously; maximum one idea per overlay).
- Kinetic typography for its own sake (the words are evidence, not a music video).
- Lower-third name titles for every speaker (faceless documentary — names appear in narration or as brief identifiers, not as broadcast graphics).
- Text competing with the visual (if the image is the evidence, the text must not cover it — place text in clear space or cut to a text card).

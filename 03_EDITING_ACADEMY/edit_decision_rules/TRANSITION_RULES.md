# TRANSITION_RULES — when (not) to use flashy transitions

## The standing rule
Hard cuts are the default. Chapter boundaries are the transitions. Decorative transitions are banned.

## The question answered
"When should we NOT use a flashy transition?" — Almost always.

## Operational rules

- IF moving between chapters/beats → THEN hard cut. The chapter title is the transition; no visual effect is needed.
- IF moving from the cold open into the rewind → THEN hard cut. The cut *is* the rewind signal.
- IF moving into the mechanism cutaway → THEN simple fade or straight cut. The cutaway is the spectacle; the transition must be invisible.
- IF moving from the final warning to the point of no return → THEN hard cut, then stillness. No bridge, no buffer.
- IF tempted by a dissolve, wipe, zoom-transition, or effect → THEN don't. There is no observed evidence for decorative transitions in the winning set, and the restraint norm forbids them.
- IF a transition would call attention to itself → THEN it's the wrong transition. The viewer should never notice a transition — only the story's movement.

## The only permitted "effects"

1. **Hard cut** (default, ~95% of transitions).
2. **Simple fade** (into the mechanism cutaway; out of the final image — maybe; test).
3. **Annotation appearance** (fade/pop of a circle, label, counter — functional, not decorative).
4. **Timeline link fill** (the chain building — functional).

## Anti-patterns (all banned)

- Zoom/spin/whip transitions (YouTube-amateur grammar — instant credibility damage in this genre).
- Dissolve montages (sentimentality the genre doesn't use).
- Page-turn, paper-texture, or "documentary-style" effect transitions (kitsch).
- Transition SFX (whooshes — never; movement is not action).
- Light-leak, film-burn, glitch effects (the genre's visual promise is evidence, not style).

## Evidence
No decorative transitions observed or evidenced in the research corpus. The chapter-boundary-as-transition system is [OBSERVED] across all chaptered videos (chapter titles function as the edit's segmentation). The restraint norm (1 exclamation mark across 14 transcripts; ≤1.6 dramatic adjectives/1k) extends to the visual track by the same logic.

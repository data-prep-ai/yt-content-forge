# VISUAL_SELECTION — the hierarchy of what goes on screen

The genre's visual promise is evidence, not spectacle (Bible §7). When the narration needs a visual, select in this order. Each level is preferred over everything below it.

## The hierarchy

1. **Primary document/photo/map** — the actual memo, the archival breach photo, the real chart. (Fascinating Horror's press-archive pipeline; Hydraulic Record's public-domain Bureau photography [OBSERVED].)
2. **Annotated diagram** — the "draw the failure" layer: red marks, labels, counters on a schematic or archival image. (Plainly Difficult's red circle; USCSB's live counter [OBSERVED].)
3. **Mechanism cutaway/animation** — for the hidden-mechanism beat only, once per video. (Alertometer's blowout-preventer [OBSERVED].)
4. **Disclosed reconstruction** — where no footage exists, labeled on screen. (Trace the Failure; Meridian Zero [OBSERVED].)
5. **Map/satellite stand-in** — where archives are thin, credited. (GEO-KOMPSAT in Banqiao [OBSERVED].)
6. **Licensed stock/contextual footage** — last resort, identified as contextual.

## Operational rules

- IF narration provides historical evidence → THEN prioritize the primary document/photo/map over generic stock footage. Stock is the last resort, never the default.
- IF narration explains spatial/mechanical relationships → THEN prefer a diagram or annotated visual over footage. Footage shows *that*; diagrams show *how*.
- IF the record is visual-dark (no footage exists) → THEN use disclosed reconstruction or map stand-in — labeled, credited, never passed off as archival.
- IF two visuals could serve → THEN choose the one closer to the primary source. The memo beats the reenactment of the memo.
- IF narration is dense with numbers → THEN the visual must be a diagram or data graphic, not a photo. Numbers need a surface to land on.
- IF the visual is only decorative (it illustrates nothing the narration says) → THEN cut it. Every visual must earn its seconds by showing something the words can't.

## Anti-patterns (observed failure modes)

- Compilation spectacle-borrowing: one event's iconic photo selling a different story (the genre's documented clickbait failure mode).
- Stock-footage montage under technical narration (the words say "piping failure," the screen shows generic water — comprehension dies).
- Reconstruction displacing available archival (if the photo exists, the AI render is dishonest even when labeled).

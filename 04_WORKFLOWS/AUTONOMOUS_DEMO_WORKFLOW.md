# AUTONOMOUS 2-MINUTE SYSTEM DEMO

## Human supplies
Nothing except permission to run the completed system.

## Muse must independently
1. Choose a subject using the channel mission, prior research, and fresh validation.
2. Prefer a subject with strong documentary evidence and a clean causal chain.
3. Build the claim ledger and source ledger.
4. Build a 2-minute story chain.
5. Write a concise narration script.
6. Identify every visual requirement.
7. Acquire evidence visuals with provenance.
8. Create diagrams/maps/reconstructions for explanation gaps.
9. Generate voice.
10. Build the edit decision list.
11. Create the actual timeline and edit.
12. Apply motion/animation only where it improves comprehension.
13. Apply music and sound according to the Editing Academy.
14. Run QA.
15. Render a finished 2-minute video.
16. Produce a demo report with all sources, rights, tools, unresolved gaps, and self-identified weaknesses.

## The demo is a system test, not a content test
Do not select a topic merely because it is easy to make. Select a topic that tests the complete pipeline: evidence, chronology, causal chain, visuals, at least one explanatory mechanism, restrained sound, and a professional documentary edit.

## No shortcut
A slideshow with narration over still images is not a pass unless the story genuinely demands that treatment and the edit demonstrates intentional motion, evidence hierarchy, pacing, graphics, and sound design.

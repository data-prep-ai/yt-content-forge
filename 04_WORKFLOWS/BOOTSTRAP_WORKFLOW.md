# ONE-TIME BOOTSTRAP WORKFLOW

This workflow runs once in a clean Muse workspace before the autonomous demo.

## Phase 1 — Read
Read the complete repo according to `10_AGENT_PROMPTS/BOOTSTRAP_ONCE.md`.

## Phase 2 — Audit
Find contradictions, missing capabilities, missing source/rights records, and assumptions that have not been tested.

## Phase 3 — Toolchain
Verify the actual environment with real tests: research, download, media conversion, voice, graphics/animation, edit/timeline/render, QA.

## Phase 4 — Asset provisioning
Build the starter reusable library using `09_SYSTEM/bootstrap/ASSET_PROVISIONING_PLAN.md`. Premium assets may only be acquired through authorized access. Save evidence of the license. Do not bypass restrictions or warehouse assets where a license forbids it.

## Phase 5 — Production system verification
Confirm templates, ledgers, state transitions, render settings, and QA paths.

## Phase 6 — Completion
Write `TOOLCHAIN_INVENTORY.md`, update `BOOTSTRAP_STATUS.md`, append to the production log, and only then set `BOOTSTRAP_COMPLETE: TRUE`.

## Hard stop
Do not choose a demo topic or start editing during bootstrap.

# Master Weekly Workflow

Cadence: 1 long-form video per week during system-building phase.

Every daily run:
1. Read `09_SYSTEM/state/CURRENT_STATE.md`.
2. Read relevant workflow and creative rules.
3. Perform only the current stage.
4. Save outputs in the current video folder.
5. Run stage-specific QA.
6. Update `CURRENT_STATE.md`.
7. Write a production log entry.
8. Stop when the day's stage is complete.

Never skip a prerequisite to save time.

# ASSET LIBRARY

This folder is the permanent media layer of the Channel OS.

## Directory meanings
- `archival/` — historically accurate photos/documents/video with provenance
- `diagrams/` — reusable explanatory graphics
- `maps/` — map components and reusable geographic treatments
- `reconstructions/` — disclosed illustrative reconstructions only
- `music/` — reusable music only where the license permits the intended use
- `sfx/` — restrained, licensed sounds; primary evidence audio is kept with the project/source record
- `motion_graphics/` — reusable motion/graphic components and presets
- `fonts/` — fonts whose licenses permit channel use
- `reusable/` — self-created or clearly reusable production assets
- `licenses/` — receipts, license PDFs, attribution files, terms snapshots when appropriate
- `_subscription_scoped/` — assets whose license is tied to an active subscription/project and should NOT be treated as permanent reusable inventory

## Registry
Every retained asset goes into `ASSET_REGISTRY.csv` with source, rights, intended use, and location.

## Principle
The library exists to speed production without weakening evidence or rights discipline.

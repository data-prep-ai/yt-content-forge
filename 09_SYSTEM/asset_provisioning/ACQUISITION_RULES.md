# ASSET ACQUISITION RULES

## Rule 1 — Evidence before aesthetics
If an authentic source exists for a factual beat, do not replace it with generic stock merely because the stock looks better.

## Rule 2 — Stock is a stand-in
Stock footage may establish environment or visual rhythm but must not be presented as footage of the event unless it is actually that event.

## Rule 3 — Reconstruction is labeled
Any synthetic reconstruction, AI-generated visual, illustrative 3D scene, or composite that could be mistaken for authentic event imagery receives a clear disclosure.

## Rule 4 — Keep provenance
Every acquired media item has a source URL/path and rights record.

## Rule 5 — Respect provider limits
Do not automate downloads in violation of provider terms. Do not evade account restrictions, watermarks, paywalls, or DRM.

## Rule 6 — Permanent vs scoped
- PERMANENT: reusable under an enduring license/ownership model.
- SUBSCRIPTION_SCOPED: use only under the provider's current terms and move/copy into the active project only as permitted.
- PROJECT_ONLY: acquired specifically for one episode.

## Rule 7 — Download only what the production system can actually use
Quality beats quantity. A curated pack is more useful than thousands of near-duplicates.

## Rule 8 — Save license evidence
When available, retain the license PDF/receipt/terms snapshot in `07_ASSET_LIBRARY/licenses/` and reference it from the ledger.

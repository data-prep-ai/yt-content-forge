# ASSET PROVIDER REGISTRY

This is a live registry. The URL is a starting point; the license terms on the day of download are authoritative.

| Provider | Main use | Access | License scope | Warehousing | Evidence to save |
|---|---|---|---|---|---|
| Artlist | music/SFX/footage/templates | subscription/account | plan-specific | verify current terms | license + download record |
| Motion Array | music/SFX/footage/templates/graphics | subscription/account | plan-specific | current terms restrict certain warehousing/automated downloads | license PDF + download record |
| YouTube Audio Library | music/SFX | YouTube Studio | YouTube use subject to track terms | generally use as project source | track metadata/attribution |
| Adobe Stock | stock video/images/graphics | subscription/purchase | asset/license specific | verify | receipt/license record |
| Envato Elements | templates/stock/audio/video | subscription/account | item/project specific | verify | item license |
| Epidemic Sound | music/SFX | subscription/account | plan/channel specific | verify | subscription + track record |
| FreeSound | SFX | per-asset | varies by license | varies | asset URL + license/attribution |

## Rule
No provider is automatically “safe” just because it is popular or paid. Check the actual current license for the exact asset/use.

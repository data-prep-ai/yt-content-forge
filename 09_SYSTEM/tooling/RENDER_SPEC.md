# RENDER SPEC

## Default long-form target
- Container: MP4
- Video: H.264
- Audio: AAC or highest-quality supported delivery format
- Resolution: 1920x1080 minimum unless source/creative plan requires otherwise
- Frame rate: consistent with the source timeline; do not mix arbitrarily
- No black frames unless intentional
- Final duration must match the approved script/edit plan

## Demo
- Target: ~2:00
- Delivery: H.264 MP4
- Include final mixed audio
- Verify file opens and can be scrubbed end-to-end

## Rule
Do not upsample poor footage just to claim higher quality. Do not alter source evidence to make it look “more cinematic.”

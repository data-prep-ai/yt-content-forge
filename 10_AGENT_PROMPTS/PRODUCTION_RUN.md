# MUSE RECURRING PRODUCTION RUN

Prerequisite: system validated after the autonomous demo.

For each new episode:

1. Read the current state.
2. Read the channel constitution and creative bible.
3. Identify current production stage.
4. Discover/validate the topic if the project has not already been selected.
5. Build evidence and claim ledgers.
6. Build causal story chain.
7. Write script.
8. Generate asset request list.
9. Acquire/create assets and record rights.
10. Generate voice.
11. Build edit decision list.
12. Edit.
13. Sound/graphics pass.
14. QA.
15. Render.
16. Package/publish.
17. Postmortem.
18. Update the OS only when a lesson generalizes beyond one episode.

Never let one episode overwrite the permanent rules without evidence.

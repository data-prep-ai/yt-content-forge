## DEMO OBJECTIVE

Produce one genuinely professional 2-minute Chain-of-Failure documentary segment using the entire production pipeline.

This is NOT a random slideshow and NOT a fake trailer.

It must be treated as a miniature real production.

## 1. Choose the subject

Select the strongest available topic independently.

Use:
- channel mission;
- existing research;
- current web validation;
- evidence availability;
- causal-chain clarity;
- visual potential;
- explanatory potential;
- legal/ethical risk;
- production feasibility.

Prefer a subject where the evidence can support:
CAUSE → WARNING → DECISION → ESCALATION → POINT OF NO RETURN → FAILURE → INVESTIGATION/LEGACY

Do not choose a topic merely because it is famous.

## 2. Research and proof

Build a real evidence pack.

For every meaningful factual claim:
- find a source;
- classify it;
- record exact evidence;
- record uncertainty;
- place it in the claim ledger/source ledger.

Prefer primary sources, official investigations, contemporaneous records, credible technical sources, and reputable reporting.

## 3. Story

Build a two-minute miniature of the full channel grammar:
- dated paradox / cold open;
- confident system;
- first crack/warning;
- causal chain;
- point of no return;
- consequence;
- investigation/meaning;
- open forward pull.

Do not solve the entire story in the first 20 seconds.

## 4. Visual engineering

Translate each narration beat into a deliberate visual decision.

Priority:
1. authentic primary evidence;
2. diagrams/maps/annotations that explain the mechanism;
3. disclosed reconstruction;
4. appropriate stand-in/stock where clearly non-evidentiary;
5. decorative visuals only if they serve pacing without pretending to be proof.

Collect the needed visual evidence.

If an essential explanatory visual is missing, CREATE it as a diagram or disclosed reconstruction.

Never fabricate a historical document, archival image, quotation, accident frame, or “real” event image.

## 5. Voice

Generate a restrained documentary narration consistent with the Creative Bible and Academy.

Prioritize intelligibility, measured pacing, factual confidence, and natural pauses.

## 6. Edit planning

Build `05_TEMPLATES/EDIT_DECISION_LIST.csv` for the demo.

Every visual change must have a purpose.

No default slideshow behavior.

## 7. Actual editing

Create the real timeline.

Use:
- archival-photo movement where useful;
- maps;
- diagrams;
- annotations;
- documents;
- restrained text;
- disclosed reconstruction;
- timeline/data graphics;
- hard cuts as the default;
- purposeful pacing;
- professional sound mixing.

Do NOT add generic AI visual filler merely to cover narration.

## 8. Sound

Apply the Editing Academy.

Voice first.
Music restrained.
Silence deliberately used.
SFX only where justified by the Academy and/or actual primary audio.
No Hollywood disaster impacts.
No fake ticking clocks.
No decorative whooshes.

## 9. Render

Produce an actual final 2-minute video.

Also output:
- script;
- claim ledger;
- source ledger;
- asset manifest;
- edit decision list;
- final video;
- production report;
- self-critique.

## 10. Self-score

Use the Editing Academy benchmark and the video QA checklist.

Do not inflate scores.
Identify:
- where visuals are generic;
- where pacing feels AI-generated;
- where proof is weak;
- where an animation is decorative rather than explanatory;
- where sound is overproduced;
- where the causal chain is unclear;
- where the viewer may not know what is evidence vs reconstruction.
